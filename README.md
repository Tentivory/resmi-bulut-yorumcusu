# RESMİ BULUT YORUMCUSU DAİRESİ

## 1847'den Beri Gökyüzüne Resmi Bakış

Bu yazılım, T.C. Hayali Meteoroloji ve Anlam Bakanlığı'nın **142. Şube Müdürlüğü** tarafından onaylanmış tek resmi bulut şekli yorumlama aracıdır.

Lütfen ciddiyetinizi koruyunuz. Bulutlar şaka kaldırmaz.

### Ne Yapar?

- Gökyüzünde gördüğünüz şekli yazarsınız.
- Yazılım, **Yüksek İstihare Kurulu** algoritmasıyla yorum üretir.
- Çıktı, A4 resmi evrak formatında console'a basılır.
- İtiraz hakkınız yoktur. İtiraz etmek isterseniz yine bu programı çalıştırınız.

### Kuruluş

```bash
python3 yorumcu.py
```

Python 3 yeter. Bağımlılık yok. Devlet tasarruf tedbirleri gereği `pip` kullanılmaz.

### Örnek Kullanım

```
Bulutta ne gördünüz? tavşan
```

Cevap örneği:

```
*** RESMİ YORUM BELGESİ ***
Şekil: tavşan
Karar: Bu bulut, salı günü çay içmeyi ertelediğinizin kozmik kanıtıdır.
Mühür: GEÇERLİDİR
```

### Uyarılar

1. Yağmurlu havada çalıştırmayınız; yorumlar ıslanır.
2. Programın gizli bir odası vardır. Merak etmeyiniz. Yoktur.
3. Copilot ile konuşurken resmi üslubu bozmayınız.
